The Challenge

What was the task?

Given a dataset of 198,000+ user comments from an online platform — including text content, interaction metadata, and internal system signals — predict which of 4 internal categories the platform assigns to each comment.

💬
Normal
~57% of data · Most common
Typical comment with average engagement. Standard replies and opinions.
⭐
Popular
High upvote engagement
Well-written comments that received strong community approval — like a "top comment" on Reddit.
🔥
Controversial
High upvotes AND downvotes
Divisive comments that split the community. Strong reactions on both sides.
👻
Ignored
Minimal engagement
Short, throwaway comments with almost no community reaction.
Methodology

How it was built

A full ML pipeline from raw text to trained model — covering cleaning, feature engineering, vectorization, model comparison, and hyperparameter tuning.

1
Data Loading & EDA
Loaded 198K training samples. Explored label distribution (heavily imbalanced — 57% Normal), comment length patterns, upvote/downvote distributions, and feature correlations.
2
Text Cleaning
Lowercased all text, stripped URLs, removed non-alphabetic characters, and normalized whitespace. Ensured consistent input for vectorization.
3
Feature Engineering
Extracted comment_len, word_count, exclaim_count, question_count from raw text. Combined with provided numerical features: upvotes, downvotes, emoticon indicators, and internal platform signals.
4
TF-IDF Vectorization
Built two vectorizers: TfidfVectorizer(analyzer='word', ngram_range=(1,2)) with 10K features for word-level patterns, and TfidfVectorizer(analyzer='char_wb', ngram_range=(3,4)) with 8K features for subword patterns. Combined with numerical features using sparse hstack.
5
Model Comparison
Compared Logistic Regression, Naive Bayes, and LightGBM. LightGBM significantly outperformed others thanks to its ability to handle sparse high-dimensional features and class imbalance.
6
Hyperparameter Tuning & Final Model
Used RandomizedSearchCV to find optimal parameters. Final model: n_estimators=300, learning_rate=0.08, class_weight='balanced'. Trained on full dataset for final predictions.
